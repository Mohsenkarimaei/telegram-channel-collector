# هسته ربات جمع‌آوری

این پوشه برای اتصال پنل به تلگرام آماده شده است.

## جریان کار
1. کانال‌های فعال از تنظیمات خوانده می‌شوند.
2. پست شامل متن، عکس/رسانه و قیمت دریافت می‌شود.
3. قیمت بر اساس تنظیم کانال (درصدی یا مبلغ ثابت) محاسبه می‌شود.
4. کد کانال مبدأ مثل `CH-001` همراه داده ثبت می‌شود.
5. انتشار در کانال مقصد در مرحله اتصال Telegram API انجام می‌شود.

## متغیرهای مورد نیاز
- `TELEGRAM_API_ID`
- `TELEGRAM_API_HASH`
- `TELEGRAM_BOT_TOKEN`
- `DESTINATION_CHANNEL`

**توکن‌ها و کلیدها نباید داخل GitHub قرار بگیرند.**
